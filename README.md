# event-booking-system
It is the homework 1 for the course CENG211 at IZTECH (İzmir Institute of Technology). Main focus of the course is object oriented programming, the project is written in the java programming language.

# Notes to my colleagues
In this project we will follow a really basic project management of a software project like that:
1) Requirement Analysis (is already done, it is the homework description pdf)
2) Design (the stage where we will think about the structure of the project, and a class diagram)
3) Implementation (after planning the project (in the design stage), we will independently work on the coding part)
4) Review (review the code and the homework description, if required go back to implementation stage again)

# Implementation of The Project
When the design stage is done, we will pass to the implementation stage.
For every individual task, create a branch if required (creating a branch is crucial because we do not want to 
interrupt each others code). And for *consistency*, please use this branch naming convension:
feat/<branchName> // the most usual branch name we will use (e.g. for booking cancellation system use: feat/booking-cancellation)
fix/<branchName> // a branch for bug fixes
... (there are also other naming conventions but probably we will only need these two for this homework)

# about pull request
All pull requests during the development phase must target the **dev** branch (i.e. must be merged into the dev branch).
Pull requests to the main branch are restricted until the homework assignment is completed.
Pull request to the dev branch requires at least 1 person to review it.
Pull request to the main branch requires all of the team members to review it.
